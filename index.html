ivx/docs ivx docs

Documents, in your browser

ivx/docs is a set of document tools that run entirely on your device. There is no server behind them, no account and no upload: you open a file, work on it, and save it back. Install it as an app and it keeps working offline.

  • Sign Place signature fields anywhere in a PDF and sign them with a real digital signature, using a key in this browser, a certificate file, or a smart card or USB token.
